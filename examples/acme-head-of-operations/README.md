# Worked example: Alex Morgan for Acme Corp, Head of Operations

A complete, fictional input set for the CV fit report: `cv.txt`, `jd.txt`, `candidate.json` and
`assessment.json`, written to the shapes in `docs/evidence-format.md` and scored by the rules in
`docs/rubric.md`.

Everything here is invented. Alex Morgan, Acme Corp, Example Payments Ltd, Northwind Bank, Contoso
Retail, Fabrikam Logistics, Globex Consulting and the University of Example are fictional, and
every web "source" is an illustrative page under example.com, not a real publication.

The CV deliberately contains 2 spelling errors, 2 grammar errors, full, partial and no-result
bullets, three AI-usage bullets (one quantified) and some stock AI phrasing, so every criterion
has something to show. Run `node bin/score.js examples/acme-head-of-operations` to produce
`scored.json`.
